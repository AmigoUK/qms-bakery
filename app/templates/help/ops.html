2. Long-running processes

The web server runs the Flask app. These are separate processes that need to be running too:

  • flask rq-worker — drains the SMS / email / training-cert async queues. Without this, every SMS is enqueued and never sent.
  • flask training-scheduler — every 60s: routine recert dispatch + reminder dispatch (3d / 7d / final).
  • flask trigger-worker — evaluates metric triggers; fires responders.
  • flask mqtt-bridge — subscribes to factory sensor MQTT topics and publishes events to Redis.

Recommended: run each via systemd or a process supervisor; on crash, restart with backoff.

3. First-time bootstrap

export INITIAL_ADMIN_EMAIL=admin@yourorg.example
export INITIAL_ADMIN_PASSWORD=''
flask init-db        # runs migrations + seeds roles/permissions + first admin
flask rq-worker &
flask training-scheduler &

4. Backup & restore

Postgres: pg_dump --format=custom nightly, retain 30 days. SQLite (dev): file copy after SQLITE_BUSY_TIMEOUT.

Critical paths to back up beyond the DB:

  • The TOTP_ENC_KEY — losing it means every TOTP-enrolled user must re-enrol. Store in a separate secrets vault.
  • The TRAINING_LINK_SIGNING_KEY (if set) — losing it invalidates every outstanding magic link.
  • The SECRET_KEY — losing it logs everyone out and breaks any signed payload. Independent of HMAC keys above.

5. TOTP key rotation

  1. Generate a new key. Set TOTP_ENC_KEY=<new> and move the old to TOTP_ENC_KEYS_OLD=<old>. Restart.
  2. Verify decryption still works (login of any TOTP-enrolled user).
  3. flask totp-rotate-keys --dry-run — reports counts.
  4. flask totp-rotate-keys --apply — re-encrypts every secret under the new key.
  5. Drop TOTP_ENC_KEYS_OLD from env. Restart.

6. Service-worker cache version

The PWA service worker caches static assets. After deploying changes to app/static/css/app.css or any app/static/js/*.js, bump CACHE_VERSION in app/static/sw.js. Old browsers will detect the change and re-fetch.

7. Production checklist (pre-launch)

  • ✓ SESSION_COOKIE_SECURE=1
  • ✓ SMTP_FROM is not the placeholder qms@example.invalid
  • ✓ SECRET_KEY ≥ 32 chars random
  • ✓ TRAINING_BASE_URL is the public HTTPS URL
  • ✓ TRUSTED_PROXY_HOPS matches your front of stack
  • ✓ TOTP_ENC_KEY set; backup is in your secrets vault
  • ✓ flask init-db ran with strong INITIAL_ADMIN_PASSWORD
  • ✓ rq-worker + training-scheduler running under supervision
