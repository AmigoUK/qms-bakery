Szkolenia — najczęstsze zadania

Wystawić linki dla całej linii naraz

  1. Wejdź na Pracownicy (/admin/training/trainees).
  2. Filtr Linia — zaznacz np. A1.
  3. Zaznacz checkbox w nagłówku tabeli (zaznaczy wszystkich widocznych).
  4. W dolnej belce wybierz kurs, naciśnij Wystaw linki.
  5. Ekran preview pokaże: ilu wystawimy, ilu pominiemy (np. „aktywny link do 2026-05-08").
  6. Naciśnij Wystaw N linków.

Każdy pracownik dostaje swój własny link — żaden nie jest współdzielony. Token jest HMAC-podpisany i unikalny.

Pracownik twierdzi, że nie dostał SMS-a

  1. Otwórz Audit (/admin/audit), filtruj po action=training_link_sent.
  2. Sprawdź czy jest wpis dla tego numeru telefonu.
  3. Jeśli wpis jest, ale SMS nie dotarł — sprawdź DLQ (kolejka błędów).
  4. Jeśli wpisu nie ma — sprawdź czy enrolment w ogóle się utworzył (lista pracownika → szczegóły).

Czemu kurs nie pojawia się na matrycy compliance?

Kurs jest na matrycy tylko gdy spełnia wszystkie warunki:

  • Ma active version — czyli choć jedną wersję z active_from w przeszłości.
  • Ta wersja ma przynajmniej jedno pytanie.
  • Ma przynajmniej jedno assignment (rola lub linia, dla których kurs jest wymagany).

Bez tych trzech rzeczy matryca traktuje kurs jako „nieprzydzielony" i nie pokazuje go.

Importuję pracowników z CSV

  1. Pracownicy → Import CSV.
  2. Pobierz szablon (Pobierz szablon).
  3. Wypełnij — kluczem stabilnym jest employee_number, nie telefon (telefon może się zmienić).
  4. Upload → ekran preview pokazuje: ilu nowych, ilu zaktualizowanych, ilu pominiętych z błędem.
  5. Sprawdź szczegóły błędów. Naciśnij Apply tylko gdy preview wygląda dobrze.

Co oznaczają kolory matrycy compliance?

  • szary — kurs nie wymagany dla tego pracownika
  • zielony — ważny certyfikat
  • jasny zielony — link wystawiony, czeka na zaliczenie
  • pomarańczowy — wygasa w najbliższych 30 dniach
  • czerwony — przeterminowany (nie dopuszczany do pracy)
  • czerwony krzyż — nigdy nie zaliczony

Czemu nie widzę przycisku „Wystaw"?

Brak Ci uprawnienia TRAINING_SEND. Mają je: admin, compliance, plant_manager. Inne role widzą listę, ale nie mogą dispatch-ować linków.

Bulk-issue mówi „Wystawiono 0, pominięto 5" — co się stało?

  1. Otwórz preview ponownie — kolumna Powód pominięcia wyjaśnia.
  2. Najczęściej: active until YYYY-MM-DD → ten pracownik ma już aktywny link tego kursu (anti-spam).
  3. Mniej częste: no_active_version → kurs nie ma aktywnej wersji.

Trigger się nie odpalił

  1. /admin/triggers/<id> — sprawdź is_active.
  2. Sprawdź cooldown_seconds — jeśli odpalił się w ciągu ostatnich N sekund, milknie.
  3. Sprawdź min_duration_seconds — metryka musiała przekraczać próg przez ten czas ciągle.
  4. /admin/audit filter action=fire_dry_run lub fire po trigger_id.

Cofnąć błędnie wystawiony certyfikat (lub wycofać dane GDPR)

Z poziomu konsoli serwera:

flask gdpr-redact --subject trainee:<id> --confirm

To wycofuje dane osobowe z dziennika audytu (zachowując łańcuch SHA-256 weryfikowalnym), wymaże podpis i adres IP z deklaracji. Akcja sama jest logowana.

Dziennik audytu i eksport danych

Dziennik audytu jest niezmienialny — każdy wpis ma SHA-256 hash poprzedniego wpisu w łańcuchu. Próba edycji rozjechałaby łańcuch i zostałaby wykryta przy weryfikacji.

Eksport DSAR (UK GDPR Art. 15 / Art. 20) — pełny zbiór danych dla podmiotu:

flask dsar-export --subject trainee:<id> --output dsar.json

  • HACCP / CCP — critical control points, measurements, automatic tickets on deviation.
  • SALSA — checklist templates, daily/weekly responses.
  • Triggers — threshold rules on metrics; responder fires SMS, email, ticket, or training link.

  • Pipelines — production-line stage definitions.
  • DLQ — failed-job queue (SMS / email / cert that didn't deliver).

Training — common tasks

Issue links to a whole production line at once

  1. Open Trainees (/admin/training/trainees).
  2. Use the Line filter — pick e.g. A1.
  3. Tick the header checkbox (selects all visible).
  4. In the bottom bar pick a course, press Issue links.
  5. Preview screen shows: how many will be issued, how many skipped (e.g. "active until 2026-05-08").
  6. Press Issue N links.

Each trainee gets their own unique link — no shared tokens. Each is HMAC-signed and unique.

"A worker says they didn't get the SMS"

  1. Open Audit (/admin/audit), filter by action=training_link_sent.
  2. Check whether there's a row for that phone number.
  3. If a row exists but the SMS didn't arrive — check DLQ (failed-job queue).
  4. If no row — check whether the enrolment got created at all (trainee detail page).

"A course doesn't appear in the compliance matrix"

A course only appears if all three of these are true:

  • It has an active version — at least one version with active_from in the past.
  • That version has at least one question.
  • It has at least one assignment (a role or line that requires it).

Without all three, the matrix treats the course as "unassigned" and hides it.

Importing trainees from CSV

  1. Trainees → Import CSV.
  2. Download the template (Download template).
  3. Fill it — the stable key is employee_number, not phone (phone may change).
  4. Upload → preview shows new / updated / errored counts.
  5. Inspect any errors. Press Apply only if the preview looks right.

Compliance-matrix colours

  • grey — course not required for this trainee
  • green — valid certificate
  • light green — link issued, awaiting completion
  • amber — expires within 30 days
  • red — overdue (not cleared for work)
  • red cross — never passed

"I don't see the Issue button"

You lack the TRAINING_SEND permission. It's granted to admin, compliance, and plant_manager. Other roles see the list but can't dispatch links.

Bulk-issue says "0 issued, 5 skipped" — what happened?

  1. Open the preview again — the Skip reason column explains.
  2. Most common: active until YYYY-MM-DD → that trainee already has a live link for this course (anti-spam).
  3. Less common: no_active_version → the course has no active version.

Trigger didn't fire

  1. /admin/triggers/<id> — check is_active.
  2. Check cooldown_seconds — if it fired in the last N seconds, it stays silent.
  3. Check min_duration_seconds — the metric had to exceed the threshold continuously for that long.
  4. /admin/audit filter action=fire_dry_run or fire by trigger_id.

Revoking a wrongly-issued certificate (or fulfilling a GDPR erasure request)

From the server console:

flask gdpr-redact --subject trainee:<id> --confirm

This redacts personal data from the audit log (keeping the SHA-256 chain verifiable), wipes signature and IP from declarations. The action itself is logged.

Audit log and data export

The audit log is immutable — every row contains a SHA-256 hash of the previous row. An attempted edit would break the chain and be detected on verification.

DSAR export (UK GDPR Art. 15 / Art. 20) — the full record-set for a subject:

flask dsar-export --subject trainee:<id> --output dsar.json
