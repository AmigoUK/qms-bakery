Goal: render WTForms field errors inline next to the input, with aria-invalid + aria-describedby so AT users get the feedback they currently miss (the form just silently re-displayed before). Usage in a template (commented to keep the translation-key drift test from picking up the example as a real reference): # {% from "_macros.html" import field_errors %} # #} {% macro field_errors(field) -%} {% if field.errors %}

{{ field.errors | join('; ') }}

{% endif %} {%- endmacro %} {# ── Navigation macros ─────────────────────────────────────────────── `nav_link` — a topbar/sub-nav link that marks itself aria-current when its endpoint matches the current request. Active match is delegated to `current_section()` (registered in app/__init__.py), which classifies endpoints into one of: operations | compliance | system, so a link to admin_training.dashboard correctly highlights the "Compliance" section even though the request endpoint lives in a different blueprint. `nav_section` — a single dropdown/group entry (label + list of child links). Marks itself aria-current="true" when any of its children match the active section. `breadcrumb` — semantic
    trail. The last segment is the current page (no link, aria-current). Earlier segments are tuples (label, url). #} {% macro nav_link(label, endpoint) -%} {% set is_current = request.endpoint == endpoint %} {{ label }} {%- endmacro %} {% macro nav_section(label, section_key, items) -%} {% set is_current = current_section() == section_key %}
    {{ label }}
    {% for child_label, child_endpoint in items %} {{ child_label }} {% endfor %}
